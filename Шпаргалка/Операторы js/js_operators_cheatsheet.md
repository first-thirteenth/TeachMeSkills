# Шпаргалка по часто используемым операторам в JavaScript

## 1. || (логическое ИЛИ)
- Возвращает первое истинное значение или последнее, если все ложные.
- Используется для выбора значения по умолчанию.

**Пример:**
```js
let userName = "";
let name = userName || "Гость";
console.log(name); // 'Гость', потому что userName пустая строка

let city = "Минск";
let result = city || "Москва";
console.log(result); // 'Минск', потому что city не пустая строка
```
**Пояснение:**
- Если переменная слева от || имеет "ложное" значение (например, пустая строка, 0, null, undefined), возвращается значение справа.
- Если слева "истинное" значение, оно и возвращается.

## 2. && (логическое И)
- Возвращает первое ложное значение или последнее, если все истинные.
- Используется для проверки нескольких условий подряд.

**Пример:**
```js
let isLoggedIn = true;
let hasAccess = false;
let canEnter = isLoggedIn && hasAccess;
console.log(canEnter); // false, потому что hasAccess = false

// Часто используется для короткой проверки:
let user = { name: "Иван" };
user && console.log(user.name); // выведет 'Иван', если user существует
```
**Пояснение:**
- Если хотя бы одно из условий слева от && "ложное", возвращается оно.
- Если все "истинные", возвращается последнее.

## 3. ! (логическое НЕ)
- Инвертирует логическое значение.
- Делает true из false и наоборот.

**Пример:**
```js
let isLoggedIn = false;
let isGuest = !isLoggedIn;
console.log(isGuest); // true, потому что isLoggedIn = false
```
**Пояснение:**
- ! превращает true в false и наоборот.

## 4. ?? (нулевое слияние)
- Возвращает первый аргумент, который не равен null или undefined.
- Отличие от ||: не реагирует на 0, "", false.

**Пример:**
```js
let input = null;
let value = input ?? "По умолчанию";
console.log(value); // 'По умолчанию', потому что input = null

let age = 0;
let userAge = age ?? 18;
console.log(userAge); // 0, потому что 0 не считается пустым для ??
```
**Пояснение:**
- ?? возвращает первый аргумент, который не null и не undefined.
- 0, пустая строка и false не считаются "пустыми" для ??.

## 5. Операторы сравнения
- `>`, `<`, `>=`, `<=` — сравнивают числа
- `==`, `!=` — сравнение по значению
- `===`, `!==` — строгое сравнение (по типу и значению)

**Пример:**
```js
let a = 5, b = 3;
if (a > b) {
	console.log("a больше b");
}

let x = "5", y = 5;
console.log(x == y);  // true, потому что == сравнивает только значения
console.log(x === y); // false, потому что === сравнивает и тип
```
**Пояснение:**
- >, <, >=, <= — сравнивают числа.
- == сравнивает только значения, === — значения и тип.

## 6. Тернарный оператор ? :
- Краткая форма if...else

**Пример:**
```js
let age = 16;
let result = age >= 18 ? "Взрослый" : "Ребёнок";
console.log(result); // 'Ребёнок', потому что age < 18
```
**Пояснение:**
- Если условие слева от ? истинно, возвращается первое значение.
- Если ложно — второе.

---
Эти операторы — основа для построения условий и логики в JavaScript. Используй их для проверки, выбора и обработки данных!

if и else — это не циклы, а условные операторы.

if выполняет код только если условие истинно (true).
else выполняет код, если условие в if ложно (false).
Циклы (for, while, do...while) нужны для многократного повторения кода.
if/else — для выбора, какой код выполнить, но не для повторения.

Пример:

if: “Если возраст больше 18 — вывести ‘Взрослый’.”
for: “Повторить 10 раз — вывести число.”
Поэтому if/else — это ветвление, а не цикл.
