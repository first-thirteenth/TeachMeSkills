# Шпаргалка по методам JavaScript

---

## СТРОКИ (String)

| Метод               | Что делает                  | Пример                                     |
| ------------------- | --------------------------- | ------------------------------------------ |
| `length`            | Длина строки                | `'hello'.length` → `5`                     |
| `toUpperCase()`     | Все буквы заглавные         | `'hello'.toUpperCase()` → `'HELLO'`        |
| `toLowerCase()`     | Все буквы строчные          | `'HELLO'.toLowerCase()` → `'hello'`        |
| `includes(str)`     | Содержит ли строку          | `'hello'.includes('ell')` → `true`         |
| `indexOf(str)`      | Индекс первого вхождения    | `'hello'.indexOf('l')` → `2`               |
| `slice(start, end)` | Вырезать часть строки       | `'hello'.slice(1, 3)` → `'el'`             |
| `replace(a, b)`     | Заменить часть строки       | `'hello'.replace('l', 'r')` → `'herlo'`    |
| `replaceAll(a, b)`  | Заменить все вхождения      | `'hello'.replaceAll('l', 'r')` → `'herro'` |
| `split(sep)`        | Разбить строку на массив    | `'a,b,c'.split(',')` → `['a','b','c']`     |
| `trim()`            | Убрать пробелы по краям     | `'  hi  '.trim()` → `'hi'`                 |
| `trimStart()`       | Убрать пробелы в начале     | `'  hi'.trimStart()` → `'hi'`              |
| `trimEnd()`         | Убрать пробелы в конце      | `'hi  '.trimEnd()` → `'hi'`                |
| `startsWith(str)`   | Начинается ли с...          | `'hello'.startsWith('he')` → `true`        |
| `endsWith(str)`     | Заканчивается ли на...      | `'hello'.endsWith('lo')` → `true`          |
| `repeat(n)`         | Повторить строку n раз      | `'ab'.repeat(3)` → `'ababab'`              |
| `padStart(n, str)`  | Дополнить в начале          | `'5'.padStart(3, '0')` → `'005'`           |
| `padEnd(n, str)`    | Дополнить в конце           | `'5'.padEnd(3, '0')` → `'500'`             |
| `charAt(i)`         | Символ по индексу           | `'hello'.charAt(1)` → `'e'`                |
| `at(i)`             | Символ по индексу (с конца) | `'hello'.at(-1)` → `'o'`                   |
| `concat(str)`       | Склеить строки              | `'hi'.concat(' world')` → `'hi world'`     |

## МАССИВЫ (Array)

| Метод                | Что делает                  | Пример                                         |
| -------------------- | --------------------------- | ---------------------------------------------- |
| `length`             | Длина массива               | `[1,2,3].length` → `3`                         |
| `push(el)`           | Добавить в конец            | `arr.push(4)`                                  |
| `pop()`              | Удалить с конца             | `arr.pop()` → последний элемент                |
| `unshift(el)`        | Добавить в начало           | `arr.unshift(0)`                               |
| `shift()`            | Удалить из начала           | `arr.shift()` → первый элемент                 |
| `includes(el)`       | Содержит ли элемент         | `[1,2,3].includes(2)` → `true`                 |
| `indexOf(el)`        | Индекс элемента             | `[1,2,3].indexOf(2)` → `1`                     |
| `reverse()`          | Перевернуть массив          | `[1,2,3].reverse()` → `[3,2,1]`                |
| `sort()`             | Сортировать                 | `[3,1,2].sort()` → `[1,2,3]`                   |
| `join(sep)`          | Склеить в строку            | `[1,2,3].join('-')` → `'1-2-3'`                |
| `slice(start, end)`  | Вырезать часть              | `[1,2,3,4].slice(1,3)` → `[2,3]`               |
| `splice(i, n)`       | Удалить/вставить элементы   | `arr.splice(1, 2)`                             |
| `concat(arr)`        | Объединить массивы          | `[1,2].concat([3,4])` → `[1,2,3,4]`            |
| `flat()`             | Вложенные массивы → плоский | `[1,[2,3]].flat()` → `[1,2,3]`                 |
| `forEach(fn)`        | Пройти по каждому элементу  | `arr.forEach(el => console.log(el))`           |
| `map(fn)`            | Создать новый массив        | `[1,2,3].map(x => x * 2)` → `[2,4,6]`          |
| `filter(fn)`         | Отфильтровать элементы      | `[1,2,3,4].filter(x => x > 2)` → `[3,4]`       |
| `reduce(fn, init)`   | Свернуть в одно значение    | `[1,2,3].reduce((acc, x) => acc + x, 0)` → `6` |
| `find(fn)`           | Найти первый элемент        | `[1,2,3].find(x => x > 1)` → `2`               |
| `findIndex(fn)`      | Найти индекс элемента       | `[1,2,3].findIndex(x => x > 1)` → `1`          |
| `some(fn)`           | Хоть один подходит?         | `[1,2,3].some(x => x > 2)` → `true`            |
| `every(fn)`          | Все подходят?               | `[1,2,3].every(x => x > 0)` → `true`           |
| `fill(val)`          | Заполнить значением         | `[1,2,3].fill(0)` → `[0,0,0]`                  |
| `Array.from(str)`    | Создать массив из строки    | `Array.from('abc')` → `['a','b','c']`          |
| `Array.isArray(val)` | Является ли массивом        | `Array.isArray([1,2])` → `true`                |

## ЧИСЛА (Number / Math)

| Метод             | Что делает              | Пример                            |
| ----------------- | ----------------------- | --------------------------------- |
| `Math.round(n)`   | Округлить               | `Math.round(4.6)` → `5`           |
| `Math.floor(n)`   | Округлить вниз          | `Math.floor(4.9)` → `4`           |
| `Math.ceil(n)`    | Округлить вверх         | `Math.ceil(4.1)` → `5`            |
| `Math.abs(n)`     | Модуль числа            | `Math.abs(-5)` → `5`              |
| `Math.max(a, b)`  | Максимум                | `Math.max(3, 7)` → `7`            |
| `Math.min(a, b)`  | Минимум                 | `Math.min(3, 7)` → `3`            |
| `Math.pow(a, b)`  | Возведение в степень    | `Math.pow(2, 3)` → `8`            |
| `Math.sqrt(n)`    | Квадратный корень       | `Math.sqrt(9)` → `3`              |
| `Math.random()`   | Случайное число 0..1    | `Math.random()` → `0.534...`      |
| `Math.trunc(n)`   | Убрать дробную часть    | `Math.trunc(4.9)` → `4`           |
| `toFixed(n)`      | Округлить до n знаков   | `(3.14159).toFixed(2)` → `'3.14'` |
| `parseInt(str)`   | Строку → целое число    | `parseInt('42px')` → `42`         |
| `parseFloat(str)` | Строку → число с точкой | `parseFloat('3.14')` → `3.14`     |
| `isNaN(val)`      | Является ли NaN         | `isNaN('abc')` → `true`           |
| `Number(val)`     | Конвертировать в число  | `Number('42')` → `42`             |

## ОБЪЕКТЫ (Object)

| Метод                        | Что делает                  | Пример                                  |
| ---------------------------- | --------------------------- | --------------------------------------- |
| `Object.keys(obj)`           | Массив ключей               | `Object.keys({a:1, b:2})` → `['a','b']` |
| `Object.values(obj)`         | Массив значений             | `Object.values({a:1, b:2})` → `[1,2]`   |
| `Object.entries(obj)`        | Массив пар [ключ, значение] | `Object.entries({a:1})` → `[['a',1]]`   |
| `Object.assign(target, src)` | Копировать свойства         | `Object.assign({}, obj)`                |
| `hasOwnProperty(key)`        | Есть ли свойство            | `obj.hasOwnProperty('a')` → `true`      |

## ПРОЧЕЕ

| Метод                 | Что делает              | Пример                                |
| --------------------- | ----------------------- | ------------------------------------- |
| `typeof val`          | Тип значения            | `typeof 'hi'` → `'string'`            |
| `String(val)`         | Конвертировать в строку | `String(42)` → `'42'`                 |
| `Boolean(val)`        | Конвертировать в булево | `Boolean(0)` → `false`                |
| `console.log()`       | Вывести в консоль       | `console.log('hi')`                   |
| `JSON.stringify(obj)` | Объект → строка JSON    | `JSON.stringify({a:1})` → `'{"a":1}'` |
| `JSON.parse(str)`     | Строка JSON → объект    | `JSON.parse('{"a":1}')` → `{a:1}`     |
