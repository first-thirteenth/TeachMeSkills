
# Шпаргалка по основным циклам в JavaScript

## Когда использовать какой цикл?

- **for** — когда известно количество повторений (например, перебор чисел от 1 до 10, обход массива по индексам).
- **while** — когда количество повторений заранее неизвестно, цикл должен работать до наступления определённого условия.
- **do...while** — когда нужно выполнить тело цикла хотя бы один раз, даже если условие сразу ложно.
- **for...of** — когда нужно перебрать все элементы массива, строки или другого итерируемого объекта.
- **for...in** — когда нужно перебрать все ключи (свойства) объекта.

**Выбор цикла зависит от задачи:**
- Если нужен простой перебор диапазона — for.
- Если не знаешь, сколько раз повторять — while.
- Если обязательно хотя бы одно выполнение — do...while.
- Если перебираешь коллекцию — for...of.
- Если перебираешь свойства объекта — for...in.

---


## 1. Цикл while

**Описание:**
Выполняет блок кода, пока условие истинно (true).

**Пример:**
```js
let i = 0;
while (i < 3) {
  console.log(i); // выводит 0, 1, 2
  i++;
}
```
**Пояснение:**
- Переменная i начинается с 0.
- Пока i меньше 3, цикл повторяется.
- На каждом шаге выводится значение i и увеличивается на 1.
- Когда i становится 3, цикл завершается.

---

## 2. Цикл do...while

**Описание:**
Сначала выполняет блок кода, потом проверяет условие. Гарантированно выполнится хотя бы один раз.

**Пример:**
```js
let i = 0;
do {
  console.log(i); // выводит 0, 1, 2
  i++;
} while (i < 3);
```
**Пояснение:**
- Сначала выполняется тело цикла, потом проверяется условие.
- Даже если условие сразу false, тело выполнится один раз.

---

## 3. Цикл for

**Описание:**
Универсальный цикл. Включает инициализацию, условие и шаг в одной строке.

**Пример:**
```js
for (let i = 0; i < 3; i++) {
  console.log(i); // выводит 0, 1, 2
}
```
**Пояснение:**
- let i = 0 — начальное значение.
- i < 3 — условие продолжения.
- i++ — шаг (увеличение на 1).
- На каждом шаге выводится i.

---

## 4. Цикл for...of

**Описание:**
Для перебора элементов массива, строки или других итерируемых объектов.

**Пример:**
```js
let arr = ["яблоко", "банан", "груша"];
for (let fruit of arr) {
  console.log(fruit);
}
```
**Пояснение:**
- На каждом шаге fruit — очередной элемент массива.
- Выводятся все элементы по порядку.

---

## 5. Цикл for...in

**Описание:**
Для перебора свойств объекта.

**Пример:**
```js
let user = {name: "Иван", age: 25};
for (let key in user) {
  console.log(key, user[key]);
}
```
**Пояснение:**
- На каждом шаге key — имя свойства объекта.
- user[key] — значение этого свойства.
- Выводятся все пары ключ-значение.

---

## 6. Прерывание и пропуск итераций

**break** — завершает цикл полностью.
**continue** — пропускает текущую итерацию и переходит к следующей.

**Пример:**
```js
for (let i = 0; i < 5; i++) {
  if (i === 2) continue; // пропустить 2
  if (i === 4) break;    // завершить цикл на 4
  console.log(i);
}
// Выведет: 0, 1, 3
```
**Пояснение:**
- Когда i = 2, срабатывает continue — эта итерация пропускается.
- Когда i = 4, срабатывает break — цикл завершается.

---

Эти конструкции — основа для работы с циклами в JavaScript. Используй их для перебора, повторения и обработки данных!
