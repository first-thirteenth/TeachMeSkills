# Вопросы по функциям в JavaScript

**1. Что такое функции и для чего нужны?**

Функция — это именованный блок кода, который можно вызывать многократно. Функции позволяют структурировать программу, повторно использовать код, делить задачи на подзадачи и делать код более читаемым и поддерживаемым.

**2. К какому типу данных относится функция?**

В JavaScript функция — это объект специального типа, то есть функция относится к типу данных "function" (на самом деле typeof возвращает "function", но это разновидность объекта).

**3. Что такое параметр и аргумент?**

Параметр — это переменная, объявленная в определении функции (например, function sum(a, b) {...}, a и b — параметры).
Аргумент — это конкретное значение, которое передаётся функции при вызове (например, sum(2, 3), 2 и 3 — аргументы).

**4. Можно ли передать больше аргументов, чем предусмотрено в параметрах функции?**

Да, можно. Лишние аргументы будут проигнорированы, если не используются через специальные объекты (arguments, rest-параметры).

**5. В каких случаях можно задать значение по умолчанию для параметра? Какие есть альтернативные способы?**

Значение по умолчанию можно задать прямо в определении функции: function foo(a = 5) {...}. Альтернативно — внутри функции с помощью проверки: a = a || 5 или через if (a === undefined) a = 5.

**6. Какая переменная является внешней относительно функции? Какая локальной?**

Внешняя переменная — объявлена вне функции и доступна внутри неё. Локальная — объявлена внутри функции и доступна только в ней.

**7. Почему не рекомендуется прибегать к использованию внешних переменных?**

Использование внешних переменных усложняет отладку, делает функцию зависимой от внешнего контекста, снижает переиспользуемость и может привести к ошибкам из-за изменений этих переменных вне функции.

**8. Выполнится ли код, записанный под строкой возврата значения?**

Нет, после return выполнение функции прекращается, и код ниже не выполняется.

**9. В чем отличие между Function Expression и Function Declaration?**

Function Declaration — объявление функции отдельной инструкцией (function foo() {...}), доступно во всём скрипте благодаря хостингу.
Function Expression — функция, присвоенная переменной (const foo = function() {...}), доступна только после строки объявления.

**10. Что такое хостинг? Какая переменная имеет хостинг let, const или var?**

Хостинг — это механизм поднятия объявлений переменных и функций в начало области видимости. var и Function Declaration поднимаются, let и const — нет (они попадают во временную "мертвую зону").

**11. Что такое колбэк и где используется?**

Колбэк — это функция, переданная как аргумент другой функции и вызываемая внутри неё. Используется для обработки событий, асинхронных операций, в методах массивов (forEach, map, filter) и др.

## Примеры задач по функциям с подробным разбором

### Задача 1. Сумма двух чисел

**Условие:**
Напишите функцию, которая принимает два числа и возвращает их сумму.

**Решение:**
```javascript
function sum(a, b) {
  return a + b;
}
let result = sum(3, 5); // result = 8
```
**Разбор:**
- `a` и `b` — параметры функции.
- `return a + b;` возвращает сумму.
- При вызове sum(3, 5) аргументы 3 и 5 подставляются вместо a и b.
- Результат сохраняется в переменную result.

---

### Задача 2. Проверка чётности числа

**Условие:**
Создайте функцию, которая принимает число и возвращает true, если оно чётное, и false — если нечётное.

**Решение:**
```javascript
function isEven(n) {
  return n % 2 === 0;
}
console.log(isEven(4)); // true
console.log(isEven(7)); // false
```
**Разбор:**
- `n % 2 === 0` — проверяет, делится ли число на 2 без остатка.
- Если да, функция возвращает true, иначе — false.

---

### Задача 3. Функция с параметром по умолчанию

**Условие:**
Напишите функцию, которая приветствует пользователя по имени. Если имя не передано, использовать "Гость".

**Решение:**
```javascript
function greet(name = "Гость") {
  return `Привет, ${name}!`;
}
console.log(greet("Анна")); // Привет, Анна!
console.log(greet());        // Привет, Гость!
```
**Разбор:**
- `name = "Гость"` — параметр по умолчанию.
- Если имя не передано, функция использует "Гость".

---

### Задача 4. Возврат значения и завершение функции

**Условие:**
Напишите функцию, которая возвращает "Положительное", если число больше 0, и "Не положительное" — иначе.

**Решение:**
```javascript
function checkNumber(num) {
  if (num > 0) {
    return "Положительное";
  }
  return "Не положительное";
}
console.log(checkNumber(5));  // Положительное
console.log(checkNumber(-2)); // Не положительное
```
**Разбор:**
- После return выполнение функции прекращается.
- Если num > 0, функция сразу возвращает "Положительное".
- Если нет — доходит до второго return.

### Задача 5. Колбэк-функция

**Условие:**
Напишите функцию, которая принимает два числа и функцию-колбэк. Колбэк применяется к этим числам.

**Решение:**
```javascript
function calculate(a, b, callback) {
  return callback(a, b);
}
function multiply(x, y) {
  return x * y;
}
console.log(calculate(2, 3, multiply)); // 6
```
**Разбор:**
- `callback` — функция, переданная как аргумент.
- Внутри calculate вызывается callback(a, b).
- Можно передавать разные функции: сложение, умножение и т.д.
