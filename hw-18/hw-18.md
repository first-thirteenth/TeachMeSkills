# Домашнее задание по функциям (hw-18)

## Базовый уровень

### Задача 1. Сумма чисел от 0 до N
Написать функцию `getSum`, которая будет высчитывать сумму чисел от нуля до переданного в нее параметра. 
> Пример: если передать 100, то результат — 5050 (0 + 1 + 2 + ... + 100)

---

### Задача 2. Переплата по кредиту
Напишите функцию, которая в качестве аргумента принимает сумму кредита и возвращает результат переплаты по кредиту:
- процентная ставка в год — 17%
- количество лет — 5
- сумма кредита не увеличивается

---

### Задача 3. Обрезка строки
Написать функцию `trimString`, которая принимает три параметра:
- строку
- значение «от»
- значение «по»
Функция возвращает переданную строку, обрезанную по значениям «от» и «по».

---

### Задача 4. Сумма цифр числа
Написать функцию `getSumNumbers`, которая принимает число и вычисляет сумму его цифр.
> Пример: для 2021 это будет 5 (2+0+2+1)

---

### Задача 5. Сумма чисел между a и b
Написать функцию `getSum`, которая принимает два целых числа a и b (могут быть положительными или отрицательными), находит сумму всех чисел между ними (включая их) и возвращает её. Если числа равны — вернуть a или b.

Примеры:
- getSum(1, 0) == 1; // 1 + 0 = 1
- getSum(1, 2) == 3; // 1 + 2 = 3
- getSum(0, 1) == 1; // 0 + 1 = 1
- getSum(1, 1) == 1; // 1
- getSum(-1, 0) == -1; // -1 + 0 = -1
- getSum(-1, 2) == 2; // -1 + 0 + 1 + 2 = 2

---

### Задача 6. Выбор функции по булевому значению
Напишите функцию `fooBoo`, которая принимает три параметра:
- булевое значение
- функцию foo (выводит в консоль своё имя)
- функцию boo (выводит в консоль своё имя)
Если булево значение true — запускается foo, иначе boo.

## Продвинутый уровень

### Задача 1. Проверка возможности построить треугольник
Реализуйте функцию, которая принимает 3 целых значения a, b, c. Функция возвращает true, если треугольник можно построить со сторонами заданной длины, и false — в любом другом случае.

### Задача 2. Разлом шоколадки
Ваша задача — разбить плитку шоколада размера n x m на маленькие квадраты 1x1. Реализуйте функцию, которая возвращает минимальное количество необходимых надломов. Если входные данные недействительны, вернуть 0.

### Задача 3. Стоимость покупки телефонов
Напишите программу для вычисления общей стоимости покупки телефонов:
- Покупайте телефоны, пока хватает денег на счету (используйте цикл)
- Для каждого телефона покупайте аксессуары
- После подсчёта суммы покупки прибавьте налог
- Выведите итоговую сумму, отформатированную со знаком валюты и двумя знаками после запятой
- Проверьте, хватает ли денег на счету
- Используйте константы для ставки налога, цены телефона, аксессуара, переменную для баланса
- Реализуйте функции для вычисления налога и форматирования цены
- Можно использовать prompt для ввода баланса
